# Contributing to FabLine

Thank you for your interest in contributing to FabLine! Follow these guidelines to ensure smooth collaboration.

## Code of Conduct
Please ensure a respectful, inclusive, and professional environment for all contributors.

## How to Contribute

### Reporting Bugs
1. Search existing issues to ensure the bug has not already been reported.
2. If not found, open a new issue using the **Bug Report** template.
3. Include reproducible steps, expected behavior, actual behavior, and error logs if applicable.

### Suggesting Enhancements
1. Open an issue using the **Feature Request** template.
2. Clearly describe the problem you want solved and proposed solutions.

### Pull Request Process
1. Fork the repository and create a branch from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Follow existing code formatting conventions and ensure variable naming is descriptive.
3. Test your changes locally on PHP 7.4 / 8.x and MySQL.
4. Commit your changes with concise, descriptive commit messages:
   ```bash
   git commit -m "feat(knitting): add batch weight validation"
   ```
5. Push to your fork and submit a Pull Request to `main`.
